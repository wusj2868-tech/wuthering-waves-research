## 2. 世界观与玩家身份

玩家扮演在索拉里斯世界苏醒的“漂泊者”。故事围绕找回记忆、追寻自身身份、结识“共鸣者”伙伴并跨越“悲鸣”展开。

## 3. 核心玩法

- 开放世界探索与多端互通体验。
- 高自由度动作战斗：极限闪避、逆势回击、声骸协战与 QTE 等。
- 通过共鸣者、武器、声骸和队伍搭配构建战斗体系。
